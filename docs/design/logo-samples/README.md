# papyri logo options

Twenty original vector concepts for review. Open `index.html` to compare Catppuccin Mocha and Latte and enlarge each numbered option. The small previews show 24 px and 16 px sizes.

Each SVG is self-contained, uses a 128 × 128 viewBox, and contains vector geometry only: no fonts, raster images, scripts, network resources, or external dependencies. Standalone SVGs use Mocha; their named CSS color variables can be overridden when embedded inline. All colors come from the [Catppuccin palette](https://catppuccin.com/palette/).

These are archived explorations. A monochrome refinement of option 06 is now the app icon; see [the canonical source and regeneration instructions](../README.md).
