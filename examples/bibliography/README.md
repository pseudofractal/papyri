# Bibliography examples

The same small acoustic-rooms library in five formats:

- `library.bib` — BibTeX/BibLaTeX, 15 references
- `library.ris` — RIS
- `library.csljson` — CSL JSON
- `library.nbib` — PubMed/MEDLINE NBIB
- `library.enw` — EndNote

Open any of them in Papyri to try the Library, Timeline, Atlas, Constellation,
and Manuscript views.
